# dsh-tui 验收清单（Release 前，真实 Windows Terminal 执行）

> 目的：你在真实终端把关键流程过一遍，确认「暂定稳定」后即可发布
> （推送 → 普通合 main → bump → npm publish，见 `docs/release-runbook.md`）。
> 前置：DHS host 在本机 `http://127.0.0.1:3080` 运行、有可用模型 key。
> 每项通过后打 `[x]`。异常即停止并回报，不回滚已共享历史。

## 0. 启动

1. 在本仓库根目录执行（任选其一，若全局安装则 `dsh-tui`）：
   ```bash
   node bin/tui.js
   ```
2. 预期：顶栏 logo banner + HUD（模型/上下文/token/成本）出现，输入框可输入。
- [ ] banner 与 HUD 正常
- [ ] 输入框闪烁光标，可输入

## 1. 对话与流式渲染

3. 发送一条含 Markdown 代码块/列表/加粗的长回复请求，观察流式打字效果与回车后落定排版。
4. 连发数条产生较长历史，确认历史长时输入框与 HUD 仍稳定（不顶飞、不闪跳）。
- [ ] 流式逐字/按批渲染不卡死
- [ ] 长历史下 follow-tail：默认跟随，PgUp/PgDn 翻页，End 回底
- [ ] 长历史下输入框/HUD 行数稳定

## 2. 输入与补全（Claude Code / vim 心智）

5. `i` / 直接输入进入 insert；`ESC`→normal（保留草稿）、再 `ESC`→清空整框。
6. 输入 `@` 后目录下钻文件名，`Tab`/`↑↓` 轮换，`Enter` 插入 `@"path"`（含空格自动引号）。
7. 输入 `/` 命中命令（如 `/status`）出现命令面板，Tab/Enter 选择执行。
8. 输入 `!` 开头非空字符串后 Enter，走 shell 命令路径（receive「运行 shell 命令」）。
9. insert 模式按 `↑`/`↓` 召回最近发的消息。
- [ ] `@` 文件补全（目录下钻 + 选择 + 插入）
- [ ] `/` 命令面板与执行
- [ ] `!` shell 路径
- [ ] insert 时 ↑/↓ 历史召回
- [ ] 双击 ESC / ESC+ESC 清空行为正确

## 3. 审批与问询（本轮重点改动）

10. 触发一个**非白名单工具**（如 `run_code` 试读高开销操作），确认审批卡片弹出：
    - `y` = 允许一次；`Y` = 本会话允许；`n` = 拒绝。
    - 重点验证新「模态锁定」：审批挂起时**打字不会进输入框**；`ESC`/`Ctrl+C` 可退出/中断。
    - `acceptEdits` 档下编辑工具自动放行、bypass 全放行。
11. 让 host 发一次 `question/requested`（提问型交互），确认**自动应答**（首选/plan-review 在 manual 档默认拒绝），回合不卡死。
- [ ] y / Y / n 三态可用
- [ ] 审批期打字不进输入框（模态锁定，`a495a3c`）
- [ ] acceptEdits / bypass 档自动放行
- [ ] 问询自动应答、回合不阻塞

## 4. 快捷键与稳定性

12. `Ctrl+C`：运行中→中断；空闲→800ms 内双按退出。
13. `Ctrl+L` 清屏（不清历史）。
14. `/status` 显示会话 ID/模型/上下文/模式。
15. `?` 帮助面板开关；`Esc` 关。
16. `Ctrl+O` 工具卡三态（collapsed/expanded/hidden）循环。
- [ ] Ctrl+C 中断与双按退出
- [ ] Ctrl+L 清屏
- [ ] /status、? 帮助
- [ ] Ctrl+O 工具卡

## 5. 优雅退出

18. 正常退出后确认：无残留临时文件（仓库根不应新增 `six-points.md` 等烟测产物）；进程干净退出无栈错。
- [ ] 无残留文件、无异常退出
